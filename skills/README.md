# Exécution du skill — qualification des impacts

Le skill [budget-impact-qualification](budget-impact-qualification/SKILL.md) est une étape de **raisonnement contrôlé**, au sein du pipeline déterministe [V2](../docs/v2-qualification-pipeline.md).

Exemple de demande à un agent : « Qualifie ligne par ligne les propositions de `data/programmes/lfi/2027/proposals.csv` vers le pivot V2. Consulte les sources primaires et le référentiel. Produis un registre de décisions sourcées, un patch de `impacts.csv` pour les seules imputations défendables, et un rapport d'écarts/risques. N'effectue aucun import ni merge. »

**Ne pas confondre** la suggestion d'un impact avec une écriture validée ; toute décision comptable doit être révisable et justifiée.
